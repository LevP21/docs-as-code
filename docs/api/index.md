# API

API предоставляет доступ к функциям анализатора резюме и позволяет извлекать навыки, образование и опыт работы кандидатов.

## Основные операции

- `POST /resumes` — загрузить текст резюме для анализа и получить результаты;
- `GET /resumes/{id}/analysis` — получить результат анализа резюме по идентификатору;
- `GET /resumes` — получить список загруженных резюме.

## Спецификация

Полное описание API находится в файле `openapi.yaml` и соответствует стандарту OpenAPI 3.0.3.
