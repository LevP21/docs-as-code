US-01. Загрузка резюме
Как соискатель,
я хочу загружать своё резюме в систему,
чтобы получить информацию о своих навыках, образовании и опыте работы.

Критерии приёмки:
- система принимает файл резюме в поддерживаемом формате;
- после загрузки система начинает обработку резюме;
- если файл не поддерживается, система отображает сообщение об ошибке.

US-02. Извлечение информации из резюме
Как специалист по подбору персонала,
я хочу автоматически извлекать навыки, образование и опыт работы из резюме,
чтобы быстрее получать необходимую информацию о кандидате.

Критерии приёмки:
- система извлекает навыки из текста резюме;
- система определяет информацию об образовании и опыте работы;
- результаты обработки отображаются в структурированном виде.

US-03. Просмотр результатов анализа
Как специалист по подбору персонала,
я хочу просматривать результаты анализа резюме,
чтобы быстро оценивать информацию о кандидате.

Критерии приёмки:
- система отображает извлечённые навыки, образование и опыт работы;
- каждый раздел результатов имеет отдельный заголовок;
- если информация в резюме отсутствует, система указывает, что данные не найдены.

UC-01. Анализ резюме
Актор: специалист по подбору персонала.

Цель: извлечь из резюме навыки, образование и опыт работы кандидата.

Предусловие: у пользователя есть резюме в поддерживаемом формате.

Основной сценарий:
1. Пользователь загружает резюме в систему.
2. Система проверяет формат файла.
3. Система извлекает текст из резюме.
4. Система анализирует текст и определяет навыки, образование и опыт работы.
5. Система отображает результаты анализа в структурированном виде.
6. Пользователь просматривает результаты.
Альтернативный сценарий:

Если система не может прочитать или обработать резюме, она отображает сообщение об ошибке.

Результат: навыки, образование и опыт работы извлечены из резюме и представлены пользователю в структурированном виде либо отображено сообщение об ошибке.
