# Анализатор резюме

Сервис автоматически извлекает из резюме информацию о навыках, образовании и опыте работы кандидата.

Основные пользователи:

- соискатель;
- специалист по подбору персонала.

Основные функции:

- загрузка резюме;
- извлечение навыков, образования и опыта работы;
- просмотр результатов анализа резюме.

---

## Комплект документации
1. Описание проекта — предназначено для всех участников проекта и содержит общую информацию о назначении и основных функциях системы.
2. Требования — предназначены для разработчиков и заказчиков, описывают функциональные и нефункциональные требования к системе.
3. Архитектура системы — предназначена для разработчиков и описывает структуру системы и взаимодействие её компонентов.
4. Документация API — предназначена для разработчиков и описывает способы взаимодействия с системой и обмена данными.
5. Документация ML-модели — предназначена для разработчиков и специалистов по машинному обучению и описывает принцип извлечения навыков, образования и опыта из резюме.
6. Руководство пользователя — предназначено для пользователей системы и содержит инструкции по загрузке резюме и просмотру результатов анализа.
