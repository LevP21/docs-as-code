# Model Card

## Общая информация

**Название модели:** `oksomu/resume-ner`

**Источник:** [Hugging Face Hub — oksomu/resume-ner](https://huggingface.co/oksomu/resume-ner)

**Автор / организация:** oksomu (автор профиля на Hugging Face). Организация не указана.

**Задача модели:** извлечение именованных сущностей (NER) из резюме с помощью модели DistilBERT.

**Язык:** английский.

## Использование в проекте

Модель oksomu/resume-ner используется в проекте «Анализатор резюме» для автоматического извлечения навыков, образования и опыта работы кандидата из текста резюме.

После отправки резюме через API POST /resumes система получает текст документа и передаёт его модели для анализа. Модель определяет значимые фрагменты текста и присваивает им соответствующие метки, например SKILL, DEGREE, INSTITUTION и TITLE.

Полученные результаты обрабатываются системой и сохраняются в структурированном виде. Затем пользователь может получить результаты анализа через GET /resumes/{id}/analysis или просмотреть список загруженных резюме через GET /resumes.

## Входные данные

Модель получает текст резюме на английском языке. Перед анализом текст может обрабатываться для нормализации форматирования.

## Выходные данные

Модель возвращает найденные фрагменты текста с метками сущностей, например `SKILL` (навык), `DEGREE` (степень образования), `INSTITUTION` (учебное заведение), `COMPANY` (компания) и `TITLE` (должность). Дополнительная обработка позволяет представить результаты в структурированном виде.

## Метрики качества

В карточке модели указаны следующие результаты внутреннего тестирования:

- Entity F1: 97,77%;
- Structured micro F1: 97,88%;
- F1 на чистых резюме: 99,18%;
- F1 на зашумлённых резюме: 69,24%.

Эти результаты получены на тестах авторского проекта и не гарантируют аналогичного качества на любых резюме.

## Ограничения

**Ограничения, указанные авторами модели:**

- Модель предназначена только для резюме на английском языке.
- Максимальная длина входного фрагмента — 512 токенов. Более длинные резюме необходимо разделять на части.
- Для сканированных документов и PDF, содержащих изображения текста, требуется предварительное распознавание текста (OCR).
- При извлечении текста из PDF с двумя колонками может нарушаться порядок содержимого.
- На зашумлённых резюме, например с ошибками OCR или некорректным форматированием, качество модели снижается.

**Потенциальные ограничения для нашего проекта:**

- Модель может некорректно извлекать навыки, образование и опыт работы, если информация представлена необычным способом или содержит ошибки.
- Для использования с русскоязычными резюме потребуется другая модель либо отдельная адаптация и проверка качества.
- Результаты модели необходимо проверять, поскольку пропущенные или ошибочно определённые данные могут повлиять на отображение информации о кандидате.

## Не рекомендуется использовать

Модель не рекомендуется применять для анализа резюме на русском языке без предварительной проверки качества. Также она не предназначена для самостоятельной оценки профессиональной пригодности кандидата или принятия кадровых решений без проверки результатов человеком.
